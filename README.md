# nikos

## Project Description

This project is named 'nikos'. It was created using `bun init` in bun v1.3.11. 'bun' is a fast all-in-one JavaScript runtime that simplifies development processes.

### Installation
To install dependencies, run:

```bash
bun install
```

### Running the Project
To run the project, execute:

```bash
bun run index.ts
```
